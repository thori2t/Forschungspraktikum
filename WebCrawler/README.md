Um eine .venv Umgebung zu erstellen
python3 -m venv .venv

Benötigte Pakete installieren:
pip install scrapy
pip install Pillow

Um die venv python Umgebung zu aktivieren im WebCrawler Folder folgenden Command eingeben:
source .venv/bin/activate
Muss in jedem neuen Terminal neu aktiviert werden.
Mit "which python" kann eingesehen werden, an welchem Ort Python installiert inst
mit deactivate kann die virtuelle Umgebung deaktiviert werden.
